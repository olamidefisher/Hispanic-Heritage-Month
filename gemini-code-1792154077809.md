# Hispanic Heritage Historical Data Explorer & STEM Calculus Lab

A complete, interactive Streamlit application designed for STEM students to explore historical macroeconomic and social indicators across Latin American nations using real-time data from the World Bank API. 

The application integrates centered polynomial regression modeling, chronological holdout validation, custom mathematical function analysis (Honors Algebra 2, Precalculus, and Calculus modes with exact derivatives and inflection points), interactive visual physics/economic simulations, editable data scenarios, and multi-format export capabilities (Excel, PDF, CSV).
